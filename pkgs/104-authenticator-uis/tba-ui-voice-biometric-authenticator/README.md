Source prototype for Voice Biometric Authenticator.

## Quick start

Use Node 22 or newer and run these commands from the repository root.

```bash
cd pkgs/104-authenticator-uis/tba-ui-voice-biometric-authenticator
npm install --no-package-lock --no-audit --no-fund
npm run build
```

Expect `dist/index.html` and bundled assets.
