Source prototype for Authorization Provenance & Decision Lineage Explorer.

## Quick start

Use Node 22 or newer and run these commands from the repository root.

```bash
cd pkgs/106-ui/tba-ui-authorization-provenance-api-decision-lineage-explorer
npm ci --no-audit --no-fund
npm run build
```

Expect `dist/index.html` and bundled assets.
