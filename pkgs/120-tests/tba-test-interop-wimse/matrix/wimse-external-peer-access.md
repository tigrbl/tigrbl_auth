# Proposed external WIMSE peer access

Source or artifact access is the first step. Directional endpoints, deployed sandbox access, and observed qualification results are tracked by the runtime closure plan.

| Peer | Access verified | Remaining runtime dependency |
| --- | --- | --- |
| go-spiffe | Built `v2.7.0` pinned to `8c6e059350b69c072aaebb41f70592faf20202c8`. Its verifier passed the direct-CA and SPIRE mTLS controls in both directions. Its Workload API client retrieved and verified a credential and bundle from the local SPIRE Agent. [Release](https://github.com/spiffe/go-spiffe/releases/tag/v2.7.0) | Cases that require external support services still depend on those providers. |

The workload controls use the SDK with lab-issued credentials. |
